Паттерн Команда для управления аквариумом
Проблема: при управлении виртуальным аквариумом пользователь выполняет различные действия: добавляет рыбок, кормит, включает подсветку, фильтр, обогреватель. Часто возникает необходимость отмены или повторения отдельных действий (например, случайное кормление, ошибочное включение света). Без использования паттерна Команда код усложняется реализация отмены и повтора, а также добавление новых операций.
Цель: разработать программу с графическим интерфейсом, которая демонстрирует применение паттерна Команда для управления аквариумом. Пользователь может выполнять отдельные действия, отменять и повторять их. Каждое действие инкапсулируется в отдельный объект команды, что позволяет гибко управлять историей и поддерживать отмену/повтор.
Реализация на основе паттерна Команда
В основе реализации лежит классическая структура паттерна Команда, включающая:
•	Интерфейс ICommand – определяет единый способ выполнения и отмены действия.
•	Конкретные команды –  FeedCommand, AddFishCommand, ToggleLightCommand, ToggleFilterCommand, ToggleHeaterCommand. Каждая хранит ссылку на получателя (Aquarium) и предыдущее состояние для отката.
•	Класс RemoteControl – инициатор (Invoker), управляет выполнением команд, хранит историю выполненных команд (history) и стек отменённых (redoStack), предоставляет методы Undo() и Redo().
•	Класс Aquarium – получатель (Receiver), содержит состояние аквариума и методы для выполнения действий.
•	Класс CommandHistory – хранит истрию выполненных команд.
