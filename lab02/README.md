Проблема:
Промышленное устройство требует непрерывного электроснабжения. В распоряжении имеются четыре типа электростанций: атомная, дизельная, гидроэлектростанция и солнечная. Каждая станция имеет ограниченный ресурс (топливо, уровень воды, солнечную энергию) и может работать только в своем формате. При исчерпании ресурса одной станции необходимо автоматически переключиться на другую, не останавливая работу устройства и не изменяя существующие системы управления станциями.
Цель:
Разработать программу с графическим интерфейсом, которая демонстрирует работу адаптера, автоматически переключающего устройство между различными типами электростанций при исчерпании их ресурса. Пользователь видит текущую станцию, уровень её ресурса и может запросить энергию, наблюдая переключение.
Реализация основана на паттерне Адаптер:
•	Интерфейс IEnergyAdapter. Целевой интерфейс, который задает единый способ получения энергии для устройства.
•	Класс EnergyAdapter. Реализует интерфейс IEnergyAdapter. Содержит список всех станций и управляет переключением между ними. При запросе энергии через метод getEnergy() выбирает текущую станцию, если её ресурс исчерпан – автоматически переключается на следующую.
•	Класс NuclearStation. Готовая система управления атомной станцией. Работает только с урановым топливом. Требует адаптации для взаимодействия с устройством.
•	Класс DieselStation. Готовая система управления дизельной станцией. Работает только с дизельным топливом.
•	Класс HydroStation. Готовая система управления гидроэлектростанцией. Работает только с уровнем воды.
•	Класс Device. Устройство, которое работает только с интерфейсом IEnergyAdapter и ничего не знает о конкретных типах станций. При запросе энергии адаптер сам выбирает активную станцию и переключается при необходимости.
