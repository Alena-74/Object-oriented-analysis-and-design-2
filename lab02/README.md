В логистической компании используются две разные системы учета товаров. Первая система работает только с линейными штрих-кодами формата EAN-13. Вторая система работает только с двухмерными QR-кодами. Сотрудникам приходится вручную переносить данные из одной системы в другую, что приводит к ошибкам и потере времени. Компании необходимо решение, которое позволит переводить информацию из одного формата в другой без потери данных, не модифицируя существующие системы.
Цель: разработать программу с графическим интерфейсом, которая демонстрирует преобразование данных между форматами штрих-кода и QR-кода с помощью паттерна Адаптер. Пользователь выбирает один из предустановленных кодов, и программа отображает его эквивалент в другом формате.
Реализация основана на паттерне Адаптер:
•	Интерфейс ITarget. Целевой интерфейс, который задает единый способ преобразования данных для всех адаптеров.
•	Класс QRSystem. Готовая система учета, работающая с QR-кодами. Требует адаптации для взаимодействия с клиентом.
•	Класс BarcodeSystem. Готовая система учета, работающая со штрих-кодами EAN-13. Требует адаптации для взаимодействия с клиентом.
•	Класс QRToBarcodeAdapter. Адаптер, который позволяет использовать QR-систему через целевой интерфейс, преобразуя QR-коды в штрих-коды.
•	Класс BarcodeToQRAdapter. Адаптер, который позволяет использовать Barcode-систему через целевой интерфейс, преобразуя штрих-коды в QR-коды.
•	Класс Client. Клиент, который работает только с целевым интерфейсом и ничего не знает о конкретных системах и адаптерах.
