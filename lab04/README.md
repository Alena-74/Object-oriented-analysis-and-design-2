Паттерн Отделенный интерфейс для генератора упражнений в тренажёрном зале
Проблема:  при разработке приложения, которое помогает пользователям подбирать упражнения для тренировок, часто возникает
необходимость реализовать разные способы выбора: случайное упражнение, подбор по группе мышц, по сложности, по доступному
инвентарю, комплексную тренировку или комбинацию фильтров. Если все эти варианты вставить в один класс, код станет
трудным для поддержки и расширения. При добавлении нового способа отбора придётся изменять существующие классы, что
нарушает принцип открытости/закрытости.
Цель: разработать программу с графическим интерфейсом, которая демонстрирует применение паттерна Отделенный интерфейс
для генерации упражнений. Пользователь может выбрать любой способ генерации (случайный, по группе мышц, по сложности,
по инвентарю, комплексную тренировку или комбинированный фильтр), а программа выдаёт соответствующий набор упражнений.
Каждый способ вынесен в отдельный класс, реализующий общий интерфейс, что позволяет легко добавлять новые алгоритмы
отбора без изменения остального кода. Реализация на основе паттерна Отделенный интерфейс
В основе реализации лежит структура паттерна, включающая:
•	WorkoutGenerator (интерфейс) – задаёт единый метод generate() для всех способов генерации упражнений.
•	RandomExerciseGenerator – отвечает за выдачу случайных упражнений без фильтрации (любые из базы).
•	MuscleGroupGenerator – генерирует упражнения только для указанной группы мышц (грудь, спина, ноги и т.д.).
•	DifficultyGenerator – подбирает упражнения с уровнем сложности не выше заданного (например, для новичков).
•	EquipmentGenerator – выбирает упражнения, которые можно выполнить с определённым типом инвентаря (штанга, гантели и т.п.).
•	FullWorkoutGenerator – формирует комплексную тренировку (например, по одному упражнению на каждую группу мышц).
•	CombinedFilterGenerator – комбинирует несколько фильтров одновременно (группа мышц + сложность + инвентарь).
•	WorkoutApp (клиент) – управляет текущим генератором через интерфейс и отображает результат, не зная конкретной реализации.
