```ks
Театральная постановка 
Проблема:
Создание спектакля требует разработки комплекса взаимосвязанных элементов: костюмов, декораций, актерской игры. Каждый жанр (Драма, Комедия, Мюзикл) диктует свои требования к этим элементам, и все они должны быть стилистически согласованы между собой. 
При использовании традиционного подхода возникает риск нарушения целостности постановки из-за случайного смешения элементов разных жанров. 
Цель:
Разработать информационную систему с графическим интерфейсом, которая позволяет режиссеру выбрать жанр спектакля и автоматически получить согласованный набор всех элементов постановки, гарантирующий их стилистическую совместимость. Система должна поддерживать экспорт описания спектакля в HTML-формат.
Описание:
Пользователь выбирает жанр спектакля, после чего система формирует следующие компоненты:
•	Костюмы — определяют внешний вид актеров, материалы, цветовую гамму
•	Декорации — описывают оформление сцены и визуальное окружение\
•	Актерская игра — определяет стиль исполнения и эмоциональную подачу
Для каждого жанра определен фиксированный набор характеристик компонентов, обеспечивающий целостность постановки:
Жанр	Костюмы	Декорации	Актерская игра
Драма	Реалистичные, приглушенные тона	Минималистичные, атмосферные	Психологическая, глубокие эмоции
Комедия	Яркие, утрированные, нелепые	Мультяшные, красочные	Гротеск, гиперболизация
Мюзикл	Блестящие, танцевальные, пайетки	Масштабные, трансформируемые	Вокально-хореографическая

Реализация основана на паттерне Абстрактная фабрика (Abstract Factory):
1.	ТеатральнаяФабрика — абстрактный класс, определяющий интерфейс для создания всех элементов спектакля.
2.	ДрамаФабрика, КомедияФабрика, МюзиклФабрика — конкретные фабрики, реализующие создание элементов для соответствующего жанра.
3.	Костюмы, Декорации,  АктерскаяИгра — абстрактные типы продуктов.
4.	ДраматическиеКостюмы, КомедийныеКостюмы, МюзикловыеКостюмы и т.д. — конкретные реализации продуктов для каждого жанра.
5.	Спектакль — результирующий объект, агрегирующий все созданные элементы.
```
